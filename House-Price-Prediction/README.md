# House Price Prediction

## Overview
This project uses Machine Learning to predict house prices based on selected property features.

## Objective
The objective is to build a simple Linear Regression model and understand how different property features affect house prices.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Method
1. Load and explore the dataset.
2. Select relevant features such as house size, number of rooms, and location.
3. Preprocess the data.
4. Split the data into training and testing sets.
5. Train a Linear Regression model.
6. Evaluate the model's predictions.

## Project Structure
- `README.md` – Project documentation
- `house_price_prediction.py` – Machine Learning implementation
- `requirements.txt` – Required Python libraries
- Dataset file – Used for training and testing the model

## Learning Outcome
This project helped me understand the basic workflow of a Machine Learning regression problem, including data preprocessing, model training, prediction, and evaluation.
